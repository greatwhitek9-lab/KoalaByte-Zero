# Koalabyte Firmware

Simple firmware repository for KoalaByte device.

- Splash/logo: assets/koalabyte_logo.png is used by firmware at boot. If the file is missing, the firmware will generate a cyberpunk koala logo (neon green & purple eyes) at runtime and save it to that path.
- To replace the splash image, put a PNG named `koalabyte_logo.png` in the `assets/` directory and reboot the device.
