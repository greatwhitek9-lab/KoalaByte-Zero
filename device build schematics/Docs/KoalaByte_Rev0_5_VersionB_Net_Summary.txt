# KoalaByte Rev0.5 Version B Interface Shield Net Summary
# Prototype harness board between Jetson dev kit, ESP32-S3, display, sensors, and radio modules.

POWER:
  +5V_MAIN: PWR_IN, LCD, USB hub, EYE1 ESP32-S3 dual 1.28in IPS eye board, optional IR LED rail
  +3V3: ESP32-S3, PN532, GPS, LoRa, CC1101, IR receiver logic
  GND: common ground across Jetson, ESP32-S3, display, sensors, radios

JETSON <-> ESP32-S3:
  UART_TX_JETSON -> UART_RX_ESP32
  UART_RX_JETSON <- UART_TX_ESP32
  I2C_SDA, I2C_SCL shared for low-speed sensors where required
  GPIO_SAFE_ENABLE -> ESP32 safety/arm input

ESP32-S3 / EYE1 peripherals:
  EYE1_UART_TX/RX or USB service -> ESP32-S3 dual-eye LCD board control
  IR_RX -> 38 kHz IR receiver output
  IR_TX -> Q1 transistor driver -> IR LEDs
  BUTTON_F1..F6, DPAD_UP/DOWN/LEFT/RIGHT, SELECT, BACK
  REAR_POWER_SWITCH input

SPI MODULES:
  SPI_SCK/MOSI/MISO shared, separate CS lines:
    LORA_CS, LORA_RST, LORA_DIO0
    CC1101_CS, CC1101_GDO0, CC1101_GDO2

UART MODULES:
  GPS_TX -> Jetson/ESP32 UART RX selectable by jumper
  GPS_RX <- Jetson/ESP32 UART TX selectable by jumper

DISPLAY:
  HDMI and USB touch remain direct cable connections to Jetson/dev kit/USB hub.
  Interface shield carries only optional 5V/GND/service wiring.

EYE DISPLAY MODULE:
  EYE1 -> ESP32-S3 1.28inch Double Eye Round LCD AIoT Development Board with onboard dual 1.28inch IPS displays.
  Legacy LED-ring eye nets/connectors are DNP unless a future accent-light revision intentionally adds them back.

PLACEMENT UPDATE — KOALABYTE ZERO:
  Product display name: Koalabyte Zero.
  CAM1 -> nose pod / central front nose assembly between the two EYE1 round LCD displays.
  IR_RX -> top-of-head / front brow IR-transparent window.
  IR_TX -> top-of-head / front brow IR-transparent window adjacent to IR_RX; drive through Q1 transistor/MOSFET stage.
  SW_PWR -> rear/back-mounted physical power switch; nose switch is removed.
  DEFAULT_EXTERNAL_ANTENNAS = 3:
    ANT_WIFI_BT -> WiFi / Bluetooth antenna, top/rear-left or top/rear service position.
    ANT_LORA_SUBGHZ -> LoRa / Sub-GHz antenna, top/rear-center or top/rear-right service position.
    ANT_SDR -> SDR antenna, right-side or rear-right SMA position.
  OPTIONAL_EXTERNAL_ANTENNAS = 4 only when ANT_LTE_OPT / LTE module is installed.
  GPS -> active ceramic patch antenna on top/rear deck, not a whip antenna.
  NFC -> internal left-ear coil, not a whip antenna.

NORMALIZED PRODUCTION TARGET:
  DS1: 800x480 HDMI touchscreen.
  CAM1: IMX708 CSI camera in nose pod.
  REG1: 5V 10-12A main rail.
  F1: 10A-class protection.
  HUB1 and SPK1 retained.
